# NAI Atelier

Атлас стилевых тегов NovelAI v5: 208 записей, объяснения, источники, поиск, копирование и конструктор строки.

Автор проекта: Шино.

Стилевые меши задают рисовку; персонаж, внешность и композиция добавляются отдельно. Взвешенные имена художников записаны как `0.8::kagoya1219 ::`. Архивные цитаты источников сохранены для проверки. Экспериментальные комбинации помечены, генерационные тесты не проводились.

Иллюстрации созданы для оформления и не являются результатами NovelAI v5.

`index.html` — самостоятельный сайт без сборки и зависимостей. GitHub Pages: main / root.
