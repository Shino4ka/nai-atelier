# Atelier — Шино

Статический сайт с двумя разделами: NovelAI и SillyTavern.

- `index.html`: стартовый экран, каталог тегов, библиотека SillyTavern; CSS и логика интерфейса находятся внутри страницы.
- `catalog.js`: 157 записей каталога без художников, мешей и авторских стилей.
- `examples.js`: публикация и чтение примеров изображений через GitHub Issues владельца.
- `guides/extblocks.html`: полный гайд с поиском, копированием кода и увеличением скриншотов.
- `downloads/`: оригинальные JSON-конфигурации и готовые ZIP-комплекты.
- `assets/`: иллюстрации, скриншоты и локальные шрифты с лицензиями.

Сайт работает без сборки и сторонних библиотек. Для GitHub Pages источником остаётся корень основной ветки.

Файлы для SillyTavern доступны отдельно и в комплектах. Их содержимое сохранено без изменений. Контрольные суммы перечислены в `downloads/files-manifest.json`.

Примеры NovelAI публикуются через интерфейс GitHub. В каталоге учитываются только записи от `Shino4ka`, привязанные к существующему ID тега. Закрытие последней публикации скрывает пример.

Для внутреннего размещения в ChatGPT Site собирается `dist/`; эта папка содержит те же страницы и материалы.
