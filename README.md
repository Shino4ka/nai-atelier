# NAI Atelier

Каталог стилевых тегов, мешей и негативов для NovelAI v5. Поиск и фильтры помогают выбрать рисовку; карточки содержат описания, промпты, примечания и ссылки на источники. Теги и имена художников можно собрать в строку и скопировать.

Автор проекта: [Шино](https://t.me/ah_ah_shino4ka).

## Локальный запуск

Из корня проекта:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Открой [локальный сайт](http://127.0.0.1:4173). Сборка и установка зависимостей не требуются.

## Файлы

- `index.html` — разметка и форма мастерской.
- `styles.css` — оформление, светлая тема и адаптивная вёрстка.
- `app.js` — поиск, фильтры, копирование, конструктор и мастерская.
- `catalog.js` — 208 записей и 20 источников.
- `assets/` — иллюстрации оформления.
- `research/` — материалы исследования тегов и негативов.
- `tests/browser.e2e.mjs` — повторяемый сценарий проверки в браузере Codex.

## Авторские стили и примеры

Мастерская готовит публикацию для GitHub. Каталог загружает записи аккаунта Shino4ka из Issues репозитория. Подтверждение публикации выполняется на GitHub; закрытие последней записи скрывает её из каталога. Изображение можно добавить ссылкой в мастерской или файлом на GitHub. Черновик и тема сохраняются в текущем браузере.

Для просмотра каталога доступ к GitHub не нужен. При ошибке загрузки авторских стилей доступна сохранённая копия, а состояние и кнопка обновления находятся в мастерской.

## Проверка

Запусти локальный сервер и открой сайт через `cua.createBrowserTab`. Импортируй `tests/browser.e2e.mjs` в браузерном REPL и вызови `runAtelierE2E(tab, browser)` с текущими привязками. Сценарий проверяет поиск, фильтры, карточки, копирование, конструктор, мастерскую, источники, темы и ширины 320–1440 px. Он использует буфер браузерной сессии и переключает локальную тему; публикации не отправляет.

Сценарий сохраняет отчёт и скриншоты каталога, карточки и мобильной версии в `verification/`. Содержимое каталога можно сверить с предыдущим коммитом по всем полям; экспорт JSON доступен в «О каталоге».

Иллюстрации оформления созданы другим генератором. Примеры стилей находятся в карточках. Происхождение записей и ограничения описаны в справке и примечаниях к источникам.
