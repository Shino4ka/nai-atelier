# Проверка гайда ExtBlocks — 2026-10-08

Источник: https://gitgud.io/sleepydraqon/ext-blocks-custom
Версия manifest: 1.0.1; проверенный HEAD: 3d2dcf2837f11c9a51a9bc95eb6f893b02dff6ce.

- README.md: типы блоков, XML-подобные теги, модели, контекст, команды и макросы.
- GeneratedPlugin.js, ApiService.js: отдельный запрос G-Block, API Preset первой конфигурации группы, отдельное системное сообщение.
- RewritePlugin.js: замена сообщения или совпавшего фрагмента, обязательный rewritten text.
- AccumulationPlugin.js: YAML-состояние и updater-операторы без собственного запроса к модели.
- ScriptPlugin.js: STscript и JavaScript; доступ к сервисам расширения и контексту SillyTavern.
- GenerationService.js: триггеры, частота, порядок исполнения, накопление до и после ожидаемой генерации.
- ContextService.js, BlockService.js: источники контекста, хранение, отдельные настройки показа и инъекции.
- SlashCommandController.js, CommandService.js: ручной запуск и is_separate.

Вступление и примеры расширены за пределы авторского каталога. API и батарейка описываются применительно к G-Block и Rewrite. Сохранён Markdown для кнопки копирования, убраны оставшиеся обращения с предположением пола пользователя.

Скриншоты 01–06 уже оформлены без системной панели. Для 07–09 сделаны самостоятельные SVG с точным окном 702×1349: верхние 187 пикселей системной панели и адресной строки скрыты. Встроенные исходные пиксели сохранены без перерисовки; те же изображения используются при увеличении и печати.
