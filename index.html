Как подключить готовый блок

  1. Установи ExtBlocks и включи расширение.
  2. Подключи сохранённый профиль в API Settings.
  3. Импортируй JSON в Preset blocks → Import.
  4. Включи блок. Для G-Block и Rewrite настрой API и назначь батарейку.

Блок и regex — два файла

  1. Конфигурацию блока импортируй в ExtBlocks.
  2. Файл оформления импортируй в Regex.
  3. Проверь, что оба элемента включены.
  4. Сохрани авторский шаблон и настройки запуска.

Модель для G-Block и Rewrite

  1. Создай и сохрани Connection Profile.
  2. Проверь ответ модели в отдельном чате.
  3. Выбери профиль для Big, Medium или Small.
  4. Назначь блоку ту же батарейку.

Как подключить

  1. Выбери в SillyTavern режим Chat Completion.
  2. В настройках пресетов основного чата нажми импорт и выбери файл пресета.
  3. Проверь, что в списке выбран новый пресет.
  4. Оба файла регексов импортируй в Расширения → Regex.
  5. Тоггл Figure Space и Use Figure Spaces включай вместе. Их можно связать через Silly Linkify.

Пресет содержит инструкции и параметры чата. Модель и своё API-подключение выбираешь отдельно.
